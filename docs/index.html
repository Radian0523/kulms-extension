iOS / Android 対応。通知機能で課題の出し忘れをゼロに。

主な機能

課題一覧

全科目の課題を締め切り順にまとめて表示。緊急度別にセクション分けされ、提出状況もひと目で確認。

ポップアップ課題一覧

ツールバー右上の拡張機能ボタン（🧩）→「KULMS+」を選択。ピン留め（📌）すればワンクリックで開けます。LMSを開かなくても、キャッシュされた課題を緊急度別にサッとチェック。ダークモード対応。

教科書パネル

KULASISシラバスから教科書・参考書情報を自動取得。Amazonリンク付きですぐに購入可能。

メモ

科目ごとにメモを残せる。締切日時を設定すれば課題と同じように緊急度表示。

サイドバー色分け

サイドバーの各科目を、最も近い締切の緊急度に応じて色分け表示。

ツール整理

使わないツールを「その他」に折りたたみ、よく使うツールだけを表示。各ツールの +/- ボタンで科目ごとにカスタマイズ可能。

科目名整理

長い科目名を自動で短縮。年度・学期情報を除去し、曜日・時限を先頭に表示。

授業中ハイライト

時間割に基づき、現在の授業にNOW、休み時間は次の授業にNEXTバッジを自動表示。

ピン留め上部バー

ヘッダー直下にピン留め科目を横並びで常時表示。サイズ 4 段階、色分けスタイルに対応。タブクリックでツール一覧をドロップダウン表示（コース行クリック展開 ON 時）。

※ 画像はイメージです。実際の表示とは異なる場合があります。

そのほかの機能

モバイル版メモ入力

タッチデバイスではモーダルオーバーレイでメモを入力。締切日時は select ドロップダウン式ピッカーで設定でき、Android WebView でも快適に操作できます。

ファイル ドラッグ＆ドロップ

課題提出ページにドロップゾーンを追加。ファイルをドラッグ＆ドロップするだけで添付できます。クリックでファイル選択ダイアログを開くことも可能。

ツリービュー拡張

授業資料をFinder/VSCode風のツリー表示に変更。インデント・矢印・フォルダ太字で階層を見やすく。↑↓←→キーでナビゲーション、Enterでファイルを開けます。全フォルダの自動展開は1回の通信で完了し、前回の結果をすぐ表示。

TA 採点支援

TAロール専用の採点効率化機能。未採点の学生へワンクリックでジャンプ、受講者一覧に状態アイコンを表示、未採点件数をリアルタイム表示。採点パネルを開いたまま背景の資料を操作可能に。

2段階認証（TOTP）を設定パネルに

KULMSの設定パネル内（「外観」と「パネル」の間）から、現在のワンタイムコード表示（30秒カウントダウン）・QRコード生成・シークレット登録/削除をポップアップを開かずに操作できます。ログイン時のOTP自動入力にも対応。

ページ先読み

サイドバーやピン留め上部バーのリンクにマウスを乗せた時点で遷移先を裏で読み込み、クリックした瞬間に表示。授業資料の全フォルダ展開も1回の通信で完了し、前回の結果をすぐに表示します（先読みは Chrome / Edge のみ）。

セキュリティと仕組み

KULMS+ は認証情報を開発者のサーバーに送信しません。データはすべてお使いの端末内に保存されます。

FIDO認証（パスキー） おすすめ

京大の2段階認証は FIDO認証（パスキー）にも対応しています。セキュリティキーや生体認証（指紋・顔認証）を登録すれば、パスワード＋ワンタイムパスワードの入力なしでログインできます。

設定方法:

  • auth.iimc.kyoto-u.ac.jp/user/ にログイン
  • 右上ハンバーガーメニュー →「FIDO認証デバイスの設定」→ 登録
多要素認証について 詳しい設定手順 (PDF)
セキュリティの詳細 2段階認証の設定 (TOTP) プライバシーポリシー
